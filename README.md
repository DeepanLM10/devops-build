# DevOps Build Project

## 🚀 Overview
This project demonstrates deployment of a React static application using Docker, Jenkins CI/CD, and AWS.

## 🛠 Tech Stack
- Docker
- Nginx
- Jenkins
- AWS EC2
- Docker Hub
- Uptime Kuma (Monitoring)

## 📦 Features
- Dockerized React app (served via Nginx)
- CI/CD pipeline with Jenkins
- Auto build & push to Docker Hub
- Deployment on AWS EC2
- Monitoring with alerts

## 🌐 Application
Runs on:
http://<EC2_PUBLIC_IP>
